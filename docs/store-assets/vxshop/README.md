# VXShop 상품 등록표

**상품은 하나뿐이다.** 대시보드에 그대로 입력하면 되는 값.

| Product ID | 상품명 | 이미지 | 가격(VX) | 재고 | 구매 제한 |
|---|---|---|---|---|---|
| `carom-no-ads` | NO ADS | `carom-no-ads.png` | 100 | 무제한 | 평생 1회 |

100 VX ≈ $1.

**Product ID는 코드와 정확히 같아야 한다.** 다르면 결제는 되고 지급은 안 된다 —
서버 `$onItemPurchased`가 `VX_PRODUCTS[productId]`를 못 찾고 `unknown_product`로 떨어진다.

## 설명란

```
광고를 없애고, 모든 스테이지 클리어 코인이 영구히 2배가 됩니다.
```

## 구매 제한은 "평생 1회"로 걸어야 한다

영구 해금이라 두 번째 결제는 아무것도 주지 않는다. 클라이언트가 "보유 중" 태그로 버튼을 막지만
그건 UI일 뿐 결제 자체를 막지는 못한다.

## 사면 무엇이 바뀌는가

| | 사기 전 | 산 뒤 |
|---|---|---|
| 클리어 코인 | 기본 | **×2** (적립 시점에 서버가 곱함) |
| 클리어 화면 "광고 보고 코인 2배" | 있음 | **사라짐** — 이미 2배라 또 주면 4배가 된다 |
| 실패 화면 "광고 보고 시간 +12초" | 광고 봐야 함 | **광고 없이 즉시** (스테이지당 1회는 그대로) |

부활 버튼을 없애지 않는 이유: 광고를 없앤 대가로 기능까지 잃으면
돈을 낸 사람이 안 낸 사람보다 나빠진다. 버튼은 남기고 광고만 걷어낸다.

코인 2배도 마찬가지다. "코인 2배" 광고가 사라지는데 그 이득까지 같이 사라지면
결제한 쪽이 코인을 덜 벌게 된다. 그래서 덤이 아니라 당연히 따라와야 하는 것이다.

## 이미지 다시 만들기

```bash
npm run vx-products
```

`public/assets`의 실제 게임 아이콘으로 합성한다.

## 팔지 않는 것

- **스킨** — 코인으로만 산다. 코인을 모을 이유가 남아 있어야 "코인 2배"가 값어치를 갖고,
  그래야 이 상품이 팔린다. 스킨을 VX로 같이 팔면 코인 경제를 스스로 망가뜨린다.
- **코인 팩** — 같은 이유. 코인을 돈으로 사게 하면 코인을 모을 이유가 사라진다.
- **진행에 영향을 주는 것** (스테이지 스킵 등) — 리더보드가 최고 도달 스테이지라
  진행 속도를 파는 순간 순위가 결제 순위가 된다.
